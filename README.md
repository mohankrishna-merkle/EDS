# EDS Project

This project is built using the Adobe Experience Manager (AEM) boilerplate.

## Environments
- Preview: https://main--{repo}--{owner}.aem.page/
- Live: https://main--{repo}--{owner}.aem.live/

## Documentation

For more information on developing with AEM, please visit [aem.live](https://www.aem.live/docs/).

## Installation

```sh
npm i
```

## Linting

```sh
npm run lint
```

## Local development

1. Install the [AEM CLI](https://github.com/adobe/helix-cli): `npm install -g @adobe/aem-cli`
2. Start AEM Proxy: `aem up` (opens your browser at `http://localhost:3000`)
3. Open the directory in your favorite IDE and start coding.
